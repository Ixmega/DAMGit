PARTE 2 - readme.txt
Se implementa la composición entre Bicicleta y Rueda. La bicicleta contiene dos objetos Rueda, uno delantero y otro trasero. Se comprueba que el diámetro sea mayor que 0 y que no se puedan asignar ruedas nulas. También se prueba la sustitución de una rueda.
Por otro lado, se implementa la composición entre Biblioteca y Libro. La biblioteca contiene un array con capacidad para cinco libros y permite añadirlos, mostrarlos y retirarlos. Los métodos de inserción y retirada devuelven un booleano para indicar si la operación se ha realizado correctamente.
En Main se prueban ambas composiciones, incluyendo situaciones de error: diámetros no válidos, ruedas nulas, intento de añadir un sexto libro y retirada de libros que no existen.
